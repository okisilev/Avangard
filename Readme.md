# NEVEREND — Премиальные путешествия (Landing Page)

Адаптивный лендинг премиального туристического оператора, созданный с нуля на чистых веб-технологиях. Проект включает в себя сложную анимацию карточек, эффект «матового стекла» (glassmorphism), динамический парсинг курсов валют и кастомные модальные окна.

## 🚀 Технологический стек
Проект написан **без использования фреймворков и сторонних библиотек** (кроме шрифтов Google Fonts). Это обеспечивает максимальную скорость загрузки и высокую производительность даже на обычном виртуальном хостинге (shared hosting).

*   **HTML5** — семантическая разметка.
*   **CSS3** — Flexbox, CSS Grid, `position: sticky`, `backdrop-filter` (glassmorphism), CSS-переменные, медиа-запросы.
*   **JavaScript (ES6+)** — работа с DOM, Fetch API (загрузка курсов валют), Intersection Observer (анимация появления элементов), обработка форм и событий скролла.

## ✨ Основные фичи
1.  **Дизайн-система**: Строгий премиальный стиль с использованием кастомной цветовой палитры (глубокий зеленый, виноградный, пыльно-голубой).
2.  **Адаптивность**: Полная адаптация под мобильные устройства, планшеты и десктопы.
3.  **Эффект «Стек» (Stacking Cards)**: На мобильных устройствах карточки туров наезжают друг на друга при скролле (реализовано на CSS `sticky` + JS).
4.  **Динамические курсы валют**: В футере автоматически подгружаются актуальные курсы ЦБ РФ (USD/EUR) и курс Биткоина через открытые API.
5.  **Модальное окно**: Удобная форма бронирования с маской ввода телефона, выбором мессенджера и красивым блюр-эффектом фона.
6.  **Оптимизация**: Встроенная ленивая загрузка изображений, плавные анимации появления элементов при скролле.

## 🛠️ Локальный запуск
Для просмотра проекта вам не нужен сервер или сборщик. Просто откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Safari, Edge).

Если вы хотите, чтобы все API-запросы (курсы валют) работали корректно, рекомендуется запустить локальный сервер (например, через VS Code Live Server), так как некоторые браузеры блокируют Fetch-запросы с `file://` протокола.
